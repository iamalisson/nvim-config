# nvim-config

Personal Neovim config, based on [LazyVim](https://github.com/LazyVim/LazyVim).

## Install on a new machine

```sh
curl -fsSL https://raw.githubusercontent.com/iamalisson/nvim-config/main/install.sh | bash
```

Or clone manually:

```sh
git clone https://github.com/iamalisson/nvim-config.git ~/.config/nvim
nvim
```

Requires Neovim >= 0.9, git, and a [Nerd Font](https://www.nerdfonts.com/) for icons.
